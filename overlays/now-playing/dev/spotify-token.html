Set up Spotify

The Now Playing Overlay can read what you are playing from Spotify. This takes four short steps, once. It only asks for permission to see what is playing, and it never sees your password.

  1. Make an app
  2. Add the address
  3. Sign in
  4. Copy it over

1. Make a Spotify app

Spotify now asks for a Premium account to make a developer app, and lets an app be used by only a few accounts (you count as one). If that does not suit you, Last.fm reads what you play from Spotify too, with a free account and no sign-in, and is explained in this overlay's README.

Open Spotify's developer dashboard, and choose Create app. Any name and description will do. If it asks which APIs you plan to use, choose Web API.

4. Copy it over

Put both of these into the overlay's Spotify settings: the client ID, and the refresh token. Then set Source to Spotify.

It has also been filled in on the dev page that opened this window.

Anyone who sees your overlay's address can read the token from its settings, so keep the address to yourself. This page sent your client ID and a one-time code to Spotify, and nothing to anyone else, and it does not keep the token.
