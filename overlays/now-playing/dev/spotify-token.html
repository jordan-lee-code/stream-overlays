Get a Spotify refresh token

The Now Playing Overlay can read what you are playing from Spotify. It needs a refresh token, which you get by signing in once, here. The page only asks for permission to see what is playing, and it never sees your password.

  2. Paste the app's client ID here:

Your refresh token

Paste it into the overlay's Spotify refresh token setting, with the client ID. Anyone who sees your overlay's address can read the token from its settings, so keep the address to yourself. This page sent your client ID and a one-time code to Spotify, and nothing to anyone else, and it does not keep the token.
