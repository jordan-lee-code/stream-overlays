# Changelog

## Unreleased

- Every overlay now works with Streamer.bot as well as StreamElements, with no change to the overlay itself. The website has a switch at the top between the two, and with Streamer.bot chosen each overlay's page gives you the address of an OBS browser source, with your settings in it, in place of the files to copy. A new `streamerbot.js` turns what Streamer.bot's WebSocket server says (cheers, subs, resubs, gifts and gift bombs, follows, raids, channel point redemptions, tips from StreamElements, Streamlabs, Ko-fi and TipeeeStream, and chat with its roles, badges and emotes) into the events the overlays already listen for, and keeps what they remember in the browser source's storage. The buttons in an overlay's StreamElements settings have no equivalent there, so the chat commands are the way to control one. Tip events are read by the field names a tip is likely to use, because Streamer.bot does not document them.
- Sub Goals, Chat Poll, Rage Bar, Spin Wheel and Squat Tracker now take the height of the StreamElements frame, as the other overlays do, so a panel that was too tall for a short box shrinks to fit it there instead of running past it. Sub Goals also has the two settings Stream Goals has under Look: Shrink to fit the box (on by default, and it was always on before) and Fill the height of the box (on by default, like Stream Goals, so the panel is as tall as the box with its content in the middle; untick it for a panel as tall as its content). Chat Poll keeps its own Grow to fill the box setting. Rage Bar, Spin Wheel and Squat Tracker scale from the box already, so they get the frame height and no new settings. Camera and Subathon already had the frame height and a Shrink to fit setting, and Be Right Back, End Credits and Start Countdown are the whole box on purpose.
- Now Playing: the Scroll speed setting is now Scroll time, the number of seconds a name takes to scroll, pauses at each end included, 12 by default and between 3 and 60. A name takes exactly that time however long it is.
- Now Playing: a name scrolls over the same set time however long it is, about 12 seconds for the whole trip at the usual speed, so a name only just too long drifts calmly instead of zipping back and forth. Only a name so long that it would have to move too fast to read takes longer.
- A new style preset, Text only (no box), for unobtrusive overlays: nothing behind the words, no frame and no shadow, just the text with a soft dark halo so it reads over whatever the stream is showing. It is in the kit and in every overlay, and the same halo applies to any preset or Custom colour set whose panel is fully clear. The overlays that draw their own panel (Chat Poll, Spin Wheel, Squat Tracker, Rage Bar, Subathon and Sub Goals) get the clear panel but not yet the halo or the frame removal.
- Every overlay's dev page has a Troubleshooting import panel. Copy the Data tab of the StreamElements widget editor, paste it in, and the overlay's settings load as they are on stream, so a problem seen there can be looked at again. Stream Goals also takes its own snapshot, with the counts and the time.
- Inside a frame, which is how StreamElements shows a widget, a card now takes the height of the frame, which is the box. The page there is only as tall as its content, so "the height of the box" used to mean "the height of the card", and a card whose text grew went past the box without shrinking to fit, and Fill the height of the box had nothing to fill. This is in the shared theme code, so it reaches every overlay that uses it, and in Subathon's own. Chat Poll, Spin Wheel, Squat Tracker, Rage Bar and Sub Goals do not use the shared shrink to fit, so they are unchanged. The page no longer scrolls inside the frame.
- Stream Goals no longer grows past its box in StreamElements when a goal is reached. The widget there sits in a page only as tall as its content, so "the height of the box" meant "the height of the card", and nothing could fill the box or shrink to fit it. The card now takes its height from the frame it sits in, and each goal's label and count stay on one line, shrinking their text a little instead of wrapping, so a row never gets taller when "Goal reached!" appears. When a reached goal raises itself, its words now fade out and back in with the new goal, instead of snapping.
- The dev page's Troubleshooting snapshot panel also takes the Data tab of the StreamElements editor, which loads the overlay's settings without needing the snapshot button.
- Adding to a goal from chat, such as `!goals add bits 500`, now fills the bar, pops the number, plays the sound and celebrates a reached goal, as a real sub or cheer does, instead of jumping to the new value. It still works while paused, and taking some off stays a quiet correction.
- Stream Goals can show a snapshot of its settings and saved counts, from a button or the `!goals snapshot` chat command, and the dev page has a Troubleshooting snapshot panel that loads one, with the same settings, counts and time, so a problem seen on stream can be looked at again.
- Stream Goals now shows a level next to a goal that raises itself, such as "Sub goal, Level 2", which goes up each time the goal is reached and raised. The wording is a setting, and it can be switched off. Each goal also has a growth setting, so every raise can be a multiple of the one before, such as 1.5 times, and the goals climb faster or slower as you go.
- Card-style panels now fill the height of their box by default, with their content in the middle, so a leaderboard, a task list or a reminder stays where it was put in OBS as entries come and go. Untick Fill the height of the box for the older panel that is as tall as its content.
- A large corner radius no longer lets bars and lines run out past the curve. Every panel now keeps its content inside its rounded corners, which matters most now that a design, radius included, can be carried from one overlay to another.

## 1.0.0

The twelve overlays and the standards they share, together in one repository, each with its history. Every version number starts again at 1.0.0.
