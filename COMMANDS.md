**Sub goals commands**
Mods and the streamer can use these. Anyone can use the last one.

**Goals**
`!incentive add 15 chat confessions` adds a goal (subs needed, then the name)
`!incentive remove 2` removes goal number 2, or `remove karaoke` by name
`!incentive clear` removes every goal

**Counting**
`!incentive subs +3` adds 3 subs (also `-2` or `set 12`)
`!incentive bits +500` adds bits from somewhere else (500 bits = 1 sub)
`!incentive reset` sets subs back to 0 and re-opens every goal

**Pausing**
`!incentive stop` stops counting new subs and bits
`!incentive start` starts counting again

**Anyone**
`!incentive` shows the panel
